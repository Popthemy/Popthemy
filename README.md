### 👨‍💻 About Me

I'm a backend-focused full-stack engineer with hands-on experience building scalable, secure APIs and production systems using **Python, Django, and Django REST Framework (DRF)**.

I own features end-to-end from architecture and authentication to deployment and integration with frontend teams. Currently strengthening my full-stack capabilities with **React** and **TypeScript** to deliver complete user-facing features.

- **Backend Architecture**: Scalable REST APIs, RBAC, JWT/OTP authentication, Celery + Redis async tasks
- **Integrations**: OpenAI, Flutterwave, Cloudinary, and third-party services
- **Frontend**: React + TypeScript (building end-to-end features)
- **Collaboration**: Worked with frontend, QA, and product teams in cross-functional environments
- **Leadership**: Co-backend lead at GDSC LAUTECH & Frontend facilitator at Build with Oyo 2026
